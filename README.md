# Códigos de R

Repositorio destinado al aprendizaje de R mediante ejemplos prácticos.
El contenido de estos dataset son de ejemplo, no contiene datos reales, fueron generados usando GEMINI FLASH.

## Contenido

- Scripts en R para análisis de datos, estadística y visualización.
- Bases de datos de ejemplo para prácticas y ejercicios.
- Material complementario para cursos y autoaprendizaje.

## Estructura del repositorio
├── DBs/    # Bases de datos utilizadas en los ejemplos      
├── *.R     # Scripts y ejercicios en R 

└── README.md     # Readme.md


## Objetivo

Este repositorio busca recopilar códigos, ejercicios y conjuntos de datos que permitan aprender y practicar programación en R, desde conceptos básicos hasta aplicaciones de análisis de datos.
